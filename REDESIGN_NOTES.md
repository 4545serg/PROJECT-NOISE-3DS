# PROJECT NOISE - redesign notes

## What changed
| File | Change |
|---|---|
| source/main.c | Settings regrouped into 7 sections (row enum reordered = D-pad order), section switcher bar + page dots, scrolling cards, About footer, minimal boot screen (top + bottom). |
| source/placeholder.h | Default cover is now the branded purple cover (was the old blue note cover). Generated by tools/embed_cover.py. |
| tools/embed_cover.py | New. Embeds resources/cover.png into placeholder.h; never edits artwork. |
| tools/make_cover.py | Marked LEGACY (it overwrites resources/cover.png). Not used by the build. |
| README.md, CHANGELOG.md, UI_REDESIGN.md | Updated to match. |

Unchanged: settings.c / settings.h (so every saved key in settings.cfg is identical), audio, lyrics, browser, search,
flow, meta, art, Makefile, resources/*, CI workflow. Icon and banner already carry the GRIMZZZZ branding and meet
smdhtool / bannertool limits, so they were kept as supplied.

## Verification done (no devkitPro in the authoring environment)
- main.c compiled with `gcc -fsyntax-only -Wall` against stub 3ds.h / citro2d.h carrying the real citro2d draw signatures:
  0 errors; the only warning (unused `buf`) also exists in the original file.
- The real row tables + row_page / row_step / card_scroll_fix code was extracted and unit-tested on the host: every
  setting is on exactly one page, TAB_FIRST is each page's first row, D-pad Down / Up walk every row in order (locked
  and unlocked EQ), never land on hidden rows, and the selected row is always inside the scroll window.
- Asset paths/sizes: icon 48x48, banner 256x128, banner.wav PCM16 mono 22.05 kHz 2.0 s, app.rsf present, all Makefile inputs exist.

## NOT verified - please check on a console after building
1. It has not been linked or run on a 3DS / Citra.
2. Look at the Display page (10 rows, scrolls) and the About page; check the boot screen on Old 3DS for smoothness.
3. Boot layout was designed from coordinates, not seen on hardware.

## Build
    make deps && make          # project_noise.3dsx
    make cia                   # needs makerom + bannertool on PATH
Or push to GitHub: .github/workflows/c-cpp.yml builds the .3dsx and .cia in Docker.
